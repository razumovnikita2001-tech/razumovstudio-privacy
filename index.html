Политика конфиденциальности сайта Razumov Studio

Дата последнего обновления: 27 октября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты информации о пользователях сайта Razumov Studio (далее — «Сайт»).

Оператор персональных данных: самозанятый Разумов Никита Сергеевич. Все действия по обработке данных соответствуют Федеральному закону № 152‑ФЗ «О персональных данных».

Основной принцип: Сайт является агрегатором ссылок на веб-приложения, разработанные тем же оператором. Сайт не запрашивает персональные данные (имя, телефон, email) и не требует регистрации. Для анализа посещаемости используется Яндекс.Метрика, которая подключается только с согласия пользователя (см. разделы 2 и 7).

2. Какие данные обрабатываются на Сайте

Сайт не запрашивает персональные данные (имя, фамилия, отчество, адрес электронной почты, номер телефона) и не требует регистрации. Для работы Сайта и аналитики обрабатываются только технические данные:

  • файлы cookie — хранят выбор пользователя о согласии на аналитику;
  • обезличенные данные о посещении: IP-адрес, тип браузера и устройства, источник перехода, просмотренные страницы и действия на Сайте — только после согласия на Яндекс.Метрику (см. раздел 7).

При переходе по ссылке с Сайта пользователь покидает Сайт и переходит в одно из приложений, каждое из которых имеет свою политику конфиденциальности.

3. Цели обработки данных

Сайт предоставляет доступ к списку приложений по ссылкам. Обезличенные технические данные обрабатываются только для анализа посещаемости и улучшения работы Сайта — при наличии согласия пользователя.

4. Правовые основания

Обработка технических данных для аналитики осуществляется на основании согласия пользователя, которое он даёт в баннере cookie. Отказ от аналитики не ограничивает доступ к Сайту. Для остальных данных правовые основания не применяются, так как персональные данные не собираются.

5. Хранение и уничтожение данных

Выбор пользователя о согласии на аналитику хранится в cookie до 1 года и может быть изменён в любой момент. Обезличенные данные о посещениях, передаваемые в Яндекс.Метрику, хранятся на стороне Яндекса в соответствии с его политикой. Собственных баз персональных данных Сайт не создаёт.

6. Использование разрешений устройства

Сайт не запрашивает разрешения на доступ к каким-либо функциям устройства (камера, микрофон, файлы, уведомления и т.п.).

7. Сторонние сервисы и передача данных

Сайт размещается на стандартных сервисах хостинга (например, GitHub Pages, Cloud Storage), которые могут собирать техническую информацию о посещениях (IP-адрес, тип браузера, время запроса) для обеспечения безопасности и анализа трафика. Эти данные обрабатываются провайдером в соответствии с его политикой конфиденциальности и не передаются нам.

Для анализа посещаемости используется Яндекс.Метрика (ООО «Яндекс», условия использования). Счётчик подключается только после явного согласия пользователя в баннере cookie. При согласии могут обрабатываться: IP-адрес, данные о браузере и устройстве, источник перехода, просмотренные страницы и действия на Сайте, а также записи Вебвизора.

Запись содержимого полей ввода в Вебвизоре отключена: значения полей маскируются, персональные данные в записи не попадают. Форм с именем, телефоном или email на Сайте нет.

Отказаться от аналитики можно в любой момент — кнопкой «Cookie» в подвале Сайта. При отказе счётчик не загружается и данные в Яндекс не передаются. За исключением обезличенных данных аналитики, передаваемых Яндексу только при согласии, мы не передаём данные третьим лицам.

8. Ссылки на приложения и их политики конфиденциальности

На Сайте размещены ссылки на веб-приложения, разработанные тем же оператором (Разумов Никита Сергеевич). Каждое приложение имеет отдельную политику конфиденциальности, которая учитывает специфику его работы (например, локальное хранение данных, использование рекламных SDK, обработка платежей и т.д.).

Перед началом использования любого приложения пользователь обязан ознакомиться с его политикой конфиденциальности, которая доступна внутри самого приложения (в разделе «Документы», «О приложении» или по прямой ссылке).

Важно: Настоящая Политика распространяется исключительно на работу Сайта-агрегатора. Обработка персональных данных в приложениях осуществляется в соответствии с их собственными политиками. Оператор несёт ответственность за обработку данных в каждом приложении в рамках его политики.

9. Права субъекта персональных данных

Поскольку обработка персональных данных на Сайте не осуществляется, права, предусмотренные 152-ФЗ (доступ, уточнение, удаление, отзыв согласия), в отношении Сайта не применимы. Тем не менее пользователь вправе:

  • отказаться от использования Сайта в любое время;
  • отозвать согласие на аналитику кнопкой «Cookie» в подвале Сайта;
  • очистить кеш, cookie и историю браузера;
  • обратиться к нам за разъяснениями (контакты в разделе 13).

При нарушении прав пользователь имеет право подать жалобу в Роскомнадзор.

10. Меры по обеспечению безопасности

Сайт использует защищённое соединение (HTTPS). Персональные данные (имя, телефон, email) на Сайте не собираются. Обезличенные данные аналитики передаются в Яндекс.Метрику только при согласии пользователя. Основные риски связаны с переходом по ссылкам на приложения — рекомендуется проверять их политики конфиденциальности перед использованием.
